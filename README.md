# Orbit Planner

离线行程、待办和健身规划 PWA。

## 本地预览

```bash
python3 -m http.server 4173
```

打开：

```text
http://localhost:4173/index.html
```

## iPhone 安装方式

1. 用 Safari 打开 GitHub Pages 发布后的 HTTPS 地址。
2. 点 Safari 底部分享按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕打开 Orbit Planner。

首次加载后，应用文件会缓存到手机上；日程、待办和训练数据保存在手机浏览器本地。

## GitHub Pages 设置

推荐发布方式：

1. 把本项目推送到 GitHub 仓库。
2. 进入仓库的 Settings。
3. 打开 Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`。
6. 保存后等待 GitHub 生成 Pages 地址。
